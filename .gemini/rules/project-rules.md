# 🛡️ Project Rules: Crime Intelligence SA

## Technical Standards
- Framework: Next.js 16 (App Router)
- Language: TypeScript
- Database: Supabase (public schema for intelligence)
- UI: Vanilla CSS + Tailwind (for utilities)
- Iconography: Lucide React (14px-18px)
- Animation: Framer Motion

## Design tokens
- Background: #050505
- Crimson: #ff3b30
- Glass: rgba(255, 255, 255, 0.03) with 12px blur

## Mission Compliance
- Every UI element must feel "premium" and "authoritative".
- Data transparency is the priority.
- No placeholders; use real intelligence data structures.
